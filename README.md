# ALPS Pure Essence — 3D Website

Trang giới thiệu ALPS Pure Essence với câu chuyện 3D theo thao tác cuộn: 5 sản phẩm (Cleanser, Toner, Serum, Face Cream, Sheet Mask) trên bệ đá xoay, camera bay tới từng sản phẩm, thông tin và giá đồng bộ từ alps.id.vn.

- `index.html` — toàn bộ trang (HTML, CSS, WebGL tự viết, không cần thư viện ngoài)
- `assets/` — mô hình 3D (JSON) và nhãn sản phẩm (PNG)

Chạy thử trên máy: `python3 -m http.server` rồi mở http://localhost:8000 (không mở trực tiếp bằng file://).
